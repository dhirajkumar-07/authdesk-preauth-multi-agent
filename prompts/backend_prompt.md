# Backend master prompt (Antigravity, Planning mode)

Build "Treatment Pre-Authorisation Decision Desk", a multi-agent system using Semantic Kernel (Python) with a FastAPI backend. Create five agents, each in its own module: Request Parser, Coverage Retrieval (RAG over plan documents), Medical Necessity (RAG over clinical guidelines), Authorisation Manager (approve, deny or more-info), and Letter Drafter. Use fan-out/fan-in orchestration (Coverage and Necessity run in parallel), human routing, and a shared Case Record that every agent reads and writes, including an audit log. Every denial must go to a human peer reviewer whose verdict is written back to the record. Output must include the decision, cited clause IDs and a draft letter. Use the existing files in data/ (plan documents, guidelines, test_cases.json). Add an evaluation runner reporting decision accuracy and clause correctness. First produce an implementation plan and task list, and do not write code until I approve.
