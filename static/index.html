Agentic Architecture

Specialised Agents & Human-in-the-Loop

Agent 1

Request Parser

Structures patient ID, requested treatment, diagnosis, and provider details from free text into structured JSON. Never invents unstated facts.

Agent 2

Coverage Retrieval

Executes clause-level RAG over plan_docs. Returns COVERED_PRIOR_AUTH, EXCLUDED, or UNCLEAR supported strictly by policy clauses.

Agent 3

Medical Necessity

Runs RAG over clinical guidelines. Determines if criteria are MET, NOT_MET, or INSUFFICIENT based on symptom duration and conservative therapy.

Agent 4

Authorisation Manager

Fans in coverage and medical necessity findings into a triage decision: APPROVE, DENY, or MORE_INFO with calibrated confidence score.

Agent 5

Letter Drafter

Drafts formal approval, denial, or missing-information response letter, citing the exact clauses. For denials, incorporates peer review details and appeal rights.

Escalation Add-on

Human Peer Reviewer

Every denial and missing-info decision is held in PENDING_HUMAN_REVIEW. A human clinician reviews the findings and issues an UPHOLD, OVERTURN, or REQUEST_INFO verdict.

Retrieval & Shared Memory

  • Clause-Level Chunking: Markdown policies and guidelines split by regex into indexed clauses (PLAN-x.x, GL-xxx-x.x).
  • Dual Collections: Pure Python TF-IDF cosine similarity indices for plan_docs and guidelines.
  • Strict Grounding Validation: Agents receive only retrieved clauses. Any cited ID not in the retrieved set is automatically dropped.
  • Reliability Fallback: If LLM call fails or quota runs out, deterministic rule engine executes safely and logs [fallback] to audit trail.
Deliverables

Expected Outputs & Benchmark

  • Tri-Fold Output: For every case: (1) Decision, (2) Grounded Clause Citations + Full Text, and (3) Draft Response Letter.
  • Peer-Review Add-On: Separates ai_decision from post-review decision. Letter drafted only after clinician verdict.
  • 10 Benchmark Cases: Tested against 4 APPROVE, 4 DENY, and 2 MORE_INFO requests in data/test_cases.json.
  • Evaluation Target: Computes Decision Accuracy, Clause Correctness, Per-Case Recall, and Confusion Matrix.
